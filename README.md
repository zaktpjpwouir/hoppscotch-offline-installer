# Hoppscotch — Free Offline Installer

![Category](https://img.shields.io/badge/API_Client-blue?style=flat-square)

## About

Hoppscotch is a free, open-source lightweight API development tool available as a web app and desktop application for Windows, macOS, and Linux. Test REST, GraphQL, and WebSocket APIs with a fast, clean interface. Self-hosting the Hoppscotch backend provides complete control for teams with privacy requirements. Hoppscotch's speed and simplicity make it a lightweight alternative to Postman.

## Common Problems & Limitations

- **Feature Depth** — Less feature-rich than Postman for complex API development workflows
- **Team Features** — Advanced team collaboration requires self-hosted or cloud deployment
- **Offline Usage** — Some features require internet connectivity
- **Extension Ecosystem** — Smaller plugin and integration ecosystem than Postman
